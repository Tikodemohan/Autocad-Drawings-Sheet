# 📐 AutoCAD Drawing Exercises

## Overview

This repository contains a collection of AutoCAD drawing exercises created for learning and practicing 2D drafting skills. The drawings help improve accuracy, technical drafting skills, and understanding of AutoCAD commands.

## Objective

The objective of this project is to practice AutoCAD 2D drafting and improve technical drawing skills through various engineering drawing exercises.

## Key Features

* 2D AutoCAD drawing exercises
* Engineering drawing practice
* Technical drafting examples
* Beginner-friendly exercises
* PDF format for easy reference

## Software Used

* AutoCAD
* SolidWorks

## Learning Outcomes

* Improved AutoCAD drafting skills
* Better understanding of drawing tools and commands
* Enhanced accuracy in creating engineering drawings

## Conclusion

This project demonstrates practical AutoCAD drafting skills through a collection of engineering drawing exercises. It is designed for students and beginners who want to strengthen their technical drawing abilities.
